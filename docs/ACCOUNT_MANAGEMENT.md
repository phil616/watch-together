# 账户与系统管理

系统不开放注册。`POST /api/v1/auth/register` 固定返回 403 / `REGISTRATION_DISABLED`，旧注册页面跳转登录。已有账户在迁移后保持原有密码和资源，角色为普通用户，不会自动把首个用户升级为管理员。

## 初始化超级管理员

在 `.env` 中配置：

```dotenv
ADMIN_USERNAME=your-admin
ADMIN_PASSWORD=replace-with-a-strong-password
ADMIN_NICKNAME=超级管理员
```

由运行环境注入变量；直接运行二进制时可使用：

```bash
set -a
source .env
set +a
./watchtogether serve
```

首次启动时，数据库中没有超级管理员才会创建。用户名必须是未使用的 3–40 位字母、数字、点、横线或下划线，密码为 10–256 字节。没有默认密码；没有超级管理员且未配置初始化凭据时拒绝启动服务。部分唯一索引限制超级管理员最多一个，数据库触发器阻止删除、禁用和降级。初始化失败会阻止该次启动，避免错误配置被忽略。

后续启动不修改已有管理员，也不会把环境中的密码当成第二套登录凭据。可在后台编辑自己的账户和密码；保存后重新登录。初始化完成后可以移除环境中的 `ADMIN_PASSWORD`。Docker Compose 会传入 `.env` 中的上述变量。

也可在启动服务前显式执行 `./watchtogether create-admin`，读取相同环境变量。忘记密码时，停止服务，设置新的 `ADMIN_PASSWORD` 后执行 `./watchtogether reset-admin-password`，再启动服务；该命令会撤销旧会话，不增加管理员。

## 权限

| 能力 | 超级管理员 | 普通用户 | 游客 |
| --- | --- | --- | --- |
| 登录正式账户 | 是 | 是 | 无需账户 |
| 上传影片、创建自己的房间 | 是 | 是 | 否 |
| 邀请未登录好友进入自己的房间 | 是 | 是 | 否 |
| 房间聊天与同步观影 | 作为房间成员 | 作为房间成员 | 仅邀请指定房间 |
| 用户创建、编辑、密码重置、禁用与删除 | 是 | 否 | 否 |
| 查看和维护全站房间、影片 | 是 | 否 | 否 |

系统管理角色与房间房主角色分开。管理后台 `/admin` 不要求管理员先加入房间；管理 API 逐请求从服务端会话和数据库校验角色。客户端隐藏入口只是界面行为。普通用户仍保持现有资源所有权与房主权限。

编辑用户（包括重置密码和禁用）会在同一数据库事务中撤销全部会话，随后断开该用户已连接的 WebSocket；握手与每条 WebSocket 消息也检查有效会话，覆盖并发撤销。恢复启用后需要重新登录。游客仍通过具有有效期和使用次数限制的邀请加入，不能访问管理 API 或其他房间。

## 管理页面

基于 Mantine 的深色管理中心，沿用现有主题，提供概览卡片、侧边导航、服务端搜索与分页、资源表格、编辑弹窗、删除确认和窄屏布局。表格可横向滚动，不撑宽手机页面。

- **概览**：用户数、禁用账户数、房间数、开放房间数、影片数和影片总容量。容量按未删除的影片记录统计，包含上传中的声明大小，不是对象存储的实时账单。
- **用户**：手动设置用户名、昵称和初始密码，编辑信息、重置密码、禁用/启用、删除。无法创建第二个超级管理员。管理员自己的账户始终启用。
- **房间**：查看所有用户房间、创建管理员自己的房间、改名、关闭、重新开放和删除。改名经过房间 Actor 串行持久化并广播，避免内存快照陈旧。
- **影片**：查看全站影片、上传管理员自己的影片、改名和删除，复用现有直传与分片上传流程。

## 删除与一致性

- 房间需先关闭再删除。删除包含成员、游客会话、邀请、聊天记录和播放检查点。Registry 串行处理 Actor 创建与移除，停止 Actor 的检查点写入后删除，避免资源复活。
- 用户仍持有房间（包括关闭房间）或未删除影片时拒绝删除，提示先处理资源；可以随时禁用该用户。已经移入清理队列的影片记录归管理员托管，以保留对象清理重试能力。
- 上传中的影片暂不允许删除；开放房间正在使用的影片也拒绝删除。数据库更新同时检查使用状态，防止检查之后才被选中。删除后不能再选择该影片。
- 影片删除先移出片库，再清理对象存储。清理失败返回明确提示，由现有每小时维护任务重试。已签发的对象存储播放地址受其原有有效期限制；撤销账户不会改变已发出的 S3 签名。
- 管理操作在 `audit_events` 记录操作者、事件类型、目标 ID 和时间，不记录密码、令牌或签名 URL。审计写入失败会记录服务日志。

## API

`/api/v1/admin` 下所有接口只允许超级管理员；写请求需同源 Origin 和 CSRF。

- `GET /stats`
- `GET, POST /users`，`GET, PATCH, DELETE /users/{userID}`
- `GET, POST /rooms`，`GET, PATCH, DELETE /rooms/{roomID}`
- `POST /rooms/{roomID}/close`、`POST /rooms/{roomID}/reopen`
- `GET /media`，`GET, PATCH, DELETE /media/{mediaID}`
- 新影片仍通过 `/api/v1/media/uploads` 的原有上传协议创建，所有权为当前管理员。

列表接受 `q`、`page`、`perPage`（默认 20、上限 100），返回 `{items,total,page,perPage}`。密码散列与对象存储密钥均不在响应中。不存在/未授权/冲突分别返回 404/401 或 403/409。

设计参考：[OWASP 权限校验](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)、[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。
